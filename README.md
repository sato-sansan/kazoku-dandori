# だんどりさん ── 家族に、もうひとり。

> 園や学校の連絡は、アプリにログインできる親にしか届かない。
> だんどりさんは、その連絡をいつもの家族のLINEに大きな字で届け、送り迎えをボタン1つで引き受けられるようにする「もうひとりの家族」です。

「Built with Claude: Japan 2026」（テーマ2：本来、誰にでも届くべきものを）の作品。開発期間 2026-11-02 12:30 〜 11-08 20:00 JST に、Claude Code でこのリポジトリに新しく作っています。

## 守っていること
- **ログインなし・新しいアプリなし。** 家族のLINEグループに招待するだけ
- **作らない。** 書いていない日付・金額・持ち物を埋めない。分からなければ1問だけ聞く
- **勝手に送らない。** 外への連絡は、家族がOKを押したものだけ。保育所・学校のアプリは裏から操作しない
- **子どもと話さない。** 相手は大人だけ
- **写真は読んだら消す。** 本名・園名・学校名は持たない

## 仕組み
```
紙のお便り／連絡アプリの画面／メール／ひとこと
        │ 写真・転送・文
        ▼
 家族のLINEグループ ── LINE Messaging API ──▶ Cloudflare Worker
   パパ・ママ・ジージ・バーバ                    │ Claude API（読む・判断／整え・翻訳）
        ▲                                        │ Durable Object（家族ごと・予定カード・送迎表・アラーム）
        │ 予定カード・名前ボタン・連絡文［コピー］  │ 写真は保存せず、読むあいだだけメモリに置く
        └────────────────────────────────────────┘
```
詳しい設計は `docs/design.md`（作成中）。

## 始め方（3手順・予定）
1. `cp .dev.vars.example .dev.vars` して、Claude APIキーとLINEのチャネルシークレット／アクセストークンを入れる（公開時は `wrangler secret put`）
2. `npm install && npx wrangler deploy`
3. LINE Developers で Webhook URL を Worker の `/line/webhook` にして、だんどりさんを家族のグループに招待。みんなでスタンプを1つ送ると名簿ができる

## 評価（読み取りの正答率）
- 公開の評価セット：架空のお便り15枚 `eval/public/`（誰でも同じ採点を再現できる）
