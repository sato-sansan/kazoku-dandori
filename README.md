# だんどりさん ── 家族に、もうひとり。

> 園や学校の連絡は、アプリにログインできる親にしか届かない。
> だんどりさんは、その連絡をいつもの家族のLINEに大きな字で届け、送り迎えをボタン1つで引き受けられるようにする「もうひとりの家族」です。

「Built with Claude: Japan 2026」（テーマ2：本来、誰にでも届くべきものを）の作品。開発期間 2026-11-02 12:30 〜 11-08 20:00 JST に、Claude Code でこのリポジトリに新しく作っています。

だんどりさんが何者で、なぜ双葉の生き物なのかは [docs/brand.md](docs/brand.md)。

## 守っていること
- **ログインなし・新しいアプリなし。** 家族のLINEグループに招待するだけ
- **作らない。** 書いていない日付・金額・持ち物を埋めない。分からなければ1問だけ聞く
- **勝手に送らない。** 外への連絡は、家族がOKを押したものだけ。保育所・学校のアプリは裏から操作しない
- **子どもと話さない。** 相手は大人だけ
- **写真は家族の置き場にしか置かない。** お便りの写真は、その家族だけが開ける置き場（R2）に残す。家族の写真は「思い出に入れておいて」「この写真 残して」と言われたものだけ。本名・園名・学校名はコードにもログにも持たない

## 仕組み
```
紙のお便り／連絡アプリの画面／メール／ひとこと
        │ 写真・転送・文
        ▼
 家族のLINEグループ ── LINE Messaging API ──▶ Cloudflare Worker
   パパ・ママ・じいじ・ばあば                    │ Claude API（読む＝Sonnet／自信が低いとき読み直し＝Opus／文を整える＝Haiku）
        ▲                                        │ Durable Object（家族ごと・SQLite・予定カード・送迎表・アラームで定時処理。Cron なし）
        │ 予定カード・名前ボタン・連絡文［コピー］  │ R2（お便りの写真。家族の合言葉つき URL からだけ見える）
        └────────────────────────────────────────┘
```
正本のデータは「予定カード」（`src/card.ts`）。画面・お知らせ・連絡文は全部これを読む。送迎の表は `src/pickup.ts`、連絡文は `src/drafts.ts`、冒険カードは `src/adventure.ts`、カレンダーは `src/calendar.ts`、家族ごとの箱は `src/family.ts`。

## 始め方（4手順）
1. `npm install`。Cloudflare で R2 を有効にし、バケット `kazoku-dandori-photos` を作る
2. 秘密を入れる：`npx wrangler secret put` で `LINE_CHANNEL_SECRET`・`LINE_CHANNEL_ACCESS_TOKEN`・`ANTHROPIC_API_KEY`・`FAMILY_PROFILE`（家族の呼び名と子どもの学年、あれば園の電話番号と「何時までに」。JSON）。手元で評価を回すときだけ `.dev.vars` に `ANTHROPIC_API_KEY`
3. `npx wrangler deploy`
4. LINE Developers で Webhook URL を Worker の `/line/webhook` にして、だんどりさんを家族のグループに招待。入った人が「わたしは ばあば」のように名乗ると名簿ができる

LINE 公式アカウントは、前から持っていた空のアカウントの名前を変えて使っている（中身の設定は全部期間中にやり直した）。
