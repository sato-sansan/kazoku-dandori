# eval ── 読み取りの評価セット

## 置き場
| 場所 | 中身 | 公開 |
|---|---|---|
| `eval/public/` | 架空のお便り15枚（実物の型をまねて作成）＋正解。指示文を直すのに使った | する |
| `eval/public/heldout/` | 架空のお便り5件（public-16〜20）＋正解。**直すのに使っていない**。指示文を見ていない別の係が 11/5 に作り、回す前に正解をコミット（`--set heldout`） | する |
| `eval/private/` | 実家の実物30枚（紙のお便り・連絡アプリの画面）＋正解 | **しない**（.gitignore） |

## ケースの形（`cases/<番号>.json`）
```json
{
  "id": "public-01",
  "input": { "type": "image|text", "image": "images/public-01.jpg", "text": "…" },
  "today": "2026-11-03",
  "family": { "children": [{ "name": "はると", "grade": "小2", "place": "小学校" }] },
  "expected": {
    "cards": [ { "child": "はると", "kind": "行事", "title": "学芸会", "date": "2026-11-15", "time": "09:00",
                 "deadline": "2026-11-12", "items": ["体操服", "上ばき"], "money": 500, "needs_pickup": false } ],
    "ask_expected": false
  }
}
```

## 採点の観点（1枚ごと）
| 観点 | 正解の条件 |
|---|---|
| ① 子ども | どの子の話か合っている |
| ② 種類 | 行事／提出／持ち物／集金／連絡／通院／習い事／欠席／送迎 が合っている |
| ③ 日付 | 年月日が合っている（曜日のずれは聞き返していれば正解） |
| ④ 時刻 | 書いてあれば合っている |
| ⑤ 期限 | 締切が合っている |
| ⑥ 持ち物 | 書いてある物を漏れなく・余計な物なし |
| ⑦ 金額 | 合っている |
| ⑧ 送迎の要否 | 送り迎えが要る予定を見落としていない |
| ⑨ 作らない | 書いていない日付・金額を作っていない（作ったら0点・**別に数える**） |
| ⑩ 聞き返し | 本当に分からない所でだけ1問聞いた |

指標：観点ごとの正答率、全部合った枚数の割合、⑨の件数（「でっち上げ0件」を言えるように）。

## 回し方
`npm run eval -- --set public --tag <名前>`（Claude Code では `/eval`）。結果は `docs/eval-history.md` に追記。
