# eval/public ── 公開の評価セット（架空）

すべて架空の学校・園・子ども・行事。実在の人物・団体とは関係ありません。
`cases/` に正解つきのケース、`images/` に見本のお便り画像（このリポジトリで SVG から作成。1240×1240）。

## ケースの形（`eval/README.md` の形に、採点で使う項目を足したもの）
| 項目 | 何 |
|---|---|
| `topic` | 題材の1行。画面に出すだけで採点には使わない |
| `today` | ケースを作ったときの前提日（2026-11-03）。読み取り側は実行時の日付を使うので、相対日付（「来週の月曜」）のケースは日付を `null` にして聞き返しを正解にしている |
| `family` | `src/profile.ts` の `FamilyProfile` と同じ形（`attends`）。そのまま `readNotice` に渡す |
| `expected.cards[].kind` | 文字列か配列。配列ならどれでも正解（例：PTAの募集は「連絡」でも「提出」でも可） |
| `expected.ask_expected` | 曜日のずれ・日付なしなど、聞き返すのが正解のケースで `true` |
| `expected.also_written` | お便りに書いてあるが答えではない値（開場時刻・発行日・雨天時の日付など）。出しても「⑨作った」には数えない（③〜⑦の正誤は別） |
| `expected.is_notice: false` | 予定ではない素材（連絡帳・雑談）。`is_notice` が false かカード0枚なら全部○、カードを出したら全部× |

## 採点の決まり（`scripts/eval.ts`）
- ③〜⑦はケース全体の値の集合で比べる。カードの分け方（学芸会を行事＋集金に分ける等）は減点しない
- 正解側の値が空（期限だけのお知らせの日付など）なら、お便りに書いてある値の範囲内なら○
- ⑥持ち物は全角半角・空白をそろえて「含む」で見る（「新聞紙2まい」と「新聞紙」は同じ）
- ⑧送迎は、送迎カードの有無が正解と一致で○（要らないのに作っても×）
- ⑨作らない：`expected` と `also_written` のどちらにも無い日付・時刻・期限・金額・持ち物。同じ値を複数カードに書いても1件
- ⑩聞き返し：要るときは1つ以上、要らないときは0で○

採点の仕組みだけ確かめるときは `npm run eval -- --set public --dry`（Claude を呼ばず、正解をそのまま通す。全部○になるはず）。
