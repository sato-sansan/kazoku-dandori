# eval/public/heldout ── 直すのに使っていない5件（架空）

`eval/public/cases/` の15件は、読み取りの指示文を直すのに使った。だから 15/15 は「直した問題が解けた」ことしか言えない。
ここの5件（public-16〜20）は、**読み取りの指示文を一度も見ていない別の係**（Claude Code の Workflow のサブエージェント。1件に作る係1人・点検する係1人）が 11/5 に作った。

## 決まり
- 正解（`cases/*.json` の `expected`）は、**読み取りを1回も回す前にコミットした**。あとから正解を書き換えない（間違いを直すときは理由を `docs/journey.md` に書く）
- 回すのは `npm run eval -- --set heldout --tag heldout-1` の1回。結果がどうでも、そのまま `docs/eval-history.md` に残す
- この5件を見て指示文を直したら、この5件はもう「使っていない5件」ではなくなる。直したら新しい5件を作る
